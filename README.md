# CCTV‑Acer backup

Backup semua skrip utama CCTV‑Acer (MWB‑15) yang dipakai untuk:
- streaming video + audio via HLS (`cctv_daemon.py`)
- deteksi gerakan dengan OpenCV (`cctv_motion.py`)
- watchdog auto‑restart (`cctv_watchdog.py`)
- API rekaman (`cctv_record_api.py`)
- utilitas lainnya

Di‑push ke repo ini setiap kali ada perubahan konfigurasi atau script.
